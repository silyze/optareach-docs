## Authentication

The API reference is generated from the Optareach OpenAPI definition and currently documents 76 operations across the platform surface, including accounts, prospect lists, campaigns, inbox, tracked searches, AI rooms, workspaces, analytics, billing, profile, notifications, and knowledge bases.

Current auth schemes exposed in the specification:

```json
"securitySchemes": {
  "cookieAuth": {
    "type": "apiKey",
    "in": "cookie",
    "name": "token"
  },
  "apiKeyAuth": {
    "type": "apiKey",
    "in": "header",
    "name": "x-api-key"
  }
}
```
